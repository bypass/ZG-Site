# Personal Website

React + Vite.

    npm install
    npm run dev      # local dev server with hot reload
    npm run build    # production build into dist/

- Text, skills, links: `src/data/content.js`
- Projects: `src/data/projects.js`
- Styles: `src/styles.css`
- Resume and 3D model: replace `public/resume.pdf` and `public/tricopter.glb` (keep the filenames)
